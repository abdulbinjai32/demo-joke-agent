One one-line joke about working beside an AI coding agent, written to `/output/entry.txt` by a
Python 3.13 program with no dependencies.

## Run it

```sh
python3 main.py
```

The program writes `entry.txt` into `/output` (override with `OUTPUT_DIR`). It reads nothing else and
uses no network.

The text is one joke on the subject, 104 characters, and the program only copies it out.
